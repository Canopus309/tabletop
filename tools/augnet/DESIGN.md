# 증강 바둑 신경망 (13줄) 설계

## 목표
1. 증강 6가지를 **이해하는** 13줄 신경망: 증강을 언제·어디에 쓸지, 무적수·결계 무리가 안 죽는다는 것까지 판단
2. **덤표 측정**: 신경망에게 "이 증강 조합에서 흑 승률이 50%가 되는 덤"을 물으면 바로 나온다 (흑·백 증강 조합 49가지, '없음' 포함)
3. (나중) 앱에 넣어 사람이 상대할 증강 바둑 AI

## 핵심: KataGo에서 출발 (웜스타트)
- 앱에 들어 있는 KataGo b10 신경망(CC0)의 가중치를 파이토치로 옮긴다 → 보통 바둑은 처음부터 강하다
- 입력에 증강 정보 채널을 덧붙이고, 그 채널의 가중치를 0으로 시작 → 처음에는 KataGo와 똑같이 둔다
- 증강 규칙으로 자기 대국을 하며 **증강 효과만 새로 배운다** (바둑을 처음부터 배우는 것보다 훨씬 빠름)

## 신경망
- 몸통: KataGo b10c128 그대로 (10블록 · 128채널 · 전역 풀링 블록)
- 입력 (칸마다): KataGo 22면 + 증강 6면
  - 내 무적 무리 · 상대 무적 무리 · 내 결계 점 · 상대 결계 점
  - 이번 차례 단계: "증강 대상을 고른 뒤 착수 대기" · "슈퍼선수 두 번째 수"
- 입력 (전역): KataGo 19개 + 내 증강 종류(6)와 남았는지 + 상대 증강 종류(6)와 남았는지
- 출력: KataGo 그대로 (수 정책 · 승률 · 집 차이 · 소유) + 증강 정책
  - 대상 칸 한 면 (무적수를 걸 돌 · 결계 점 · 저격할 돌; 가진 증강에 따라 뜻이 정해짐)
  - '지금 쓰기' 값 둘 (슈퍼선수 · 되감기)

## 한 차례를 단계로 나눔 (탐색이 증강을 다루는 법)
- 증강 쓰기 → 대상 고르기 → 착수를 각각 탐색 나무의 한 마디로 둔다
  - 결계: 쓰기 → 결계 점 → 착수
  - 무적수: 쓰기 → 내 돌 → 착수
  - 슈퍼선수: 쓰기 → 첫 수 → 둘째 수
  - 저격: 쓰기 → 상대 돌 (차례 끝)
  - 되감기: 쓰기 → (두 차례 전 장면) → 착수
- 패왕: 규칙(패 금지를 무시)과 입력 채널로만

## 자기 대국 (CPU + GPU)
- Node: 대국 규칙과 탐색 (규칙은 이미 검사를 마친 `go/aug/aug.js` · `tools/aug/augboard.js`), 수십 판을 동시에
- 파이썬: 신경망 계산 (GPU, 여러 판의 장면을 묶어서 한 번에) 과 학습
- 둘은 이 PC 안의 연결(소켓)로 주고받는다
- 판마다 흑·백 증강을 무작위로 (없음 포함), 덤도 넓은 범위에서 무작위로 → 증강 조합과 덤에 따른 승률을 배운다
- 한 수에 100~400번 탐색 (KataGo처럼 일부 수만 깊게 읽어 빠르게)

## 학습
- 자기 대국 기록(장면마다 탐색 결과 · 최종 승패 · 집 차이 · 소유)을 쌓고 KataGo식 손실로 학습 → 새 신경망으로 다시 자기 대국 (반복)
- 진행 확인: 증강을 쓰는 비율·시점, 이전 신경망 상대 승률, 시험 장면 (예: 무적 무리를 계속 공격하는가)

## 예상 시간 (RTX 4060, 재 봐야 함)
- 13줄 b10 신경망 계산: 초당 3,000~6,000장면 예상
- 한 판 ≈ 150수 × 200번 탐색 ≈ 3만 장면 → 5~10초/판 → 하루 1만~1.5만 판
- 하루이틀 안에 증강 쓰는 법이 보이기 시작, 덤표는 3~5일 학습 뒤 측정 (얼마나 걸릴지 장담 못 함)

## 만드는 순서 (단계마다 확인)
1. 파이썬 + 파이토치(CUDA) 설치 (약 3GB)
2. KataGo b10 → 파이토치로 옮기고, 같은 장면에서 앱(`go/katago.js`)과 출력이 같은지 확인
3. 증강 입력·출력을 붙이고, 새 가중치가 0일 때 출력이 KataGo 그대로인지 확인
4. 신경망 계산 서버 + Node 자기 대국 (대국 기록 저장)
5. 학습 반복 + 진행 지표
6. 덤표 측정 → 앱 덤표 수정 · (나중) 앱용 AI로 내보내기

## 위험
- 만들 것이 많다 (1~4단계에 반나절~하루). 학습이 잘 될지는 보장 못 한다
- 노트북 GPU를 며칠 풀가동 (발열·소음), 그동안 PC가 느려진다
- 무적수·결계는 KataGo가 본 적 없는 상황이라 배우는 데 오래 걸릴 수 있다
- 측정값은 'KataGo 기반 AI 수준'의 덤 (몬테카를로보다 훨씬 강하지만 사람과는 다를 수 있음)
